# Angular Lens

A lightweight VS Code extension for staying up to date with Angular releases directly from the Activity Bar.

## Overview

Angular Lens helps you quickly browse the latest published Angular versions, grouped by major release. Each item includes a direct link to the official release page and displays release notes when available.

## Features

- View the latest stable Angular releases
- Organize releases by major version
- Open release details and changelogs from within VS Code
- Minimal, focused experience without leaving the editor

## Commands

- View: Show Angular Lens
- Angular Lens: Open Releases

## Why use it

Perfect for Angular developers who want a fast, distraction-free way to monitor release updates while working in VS Code.
